## Actualizar tu repositorio de GitHub Pages
1. Descomprime este ZIP.
2. En tu repositorio `Gouki-y-D-D`, sube y reemplaza `index.html` y agrega `manifest.json`, `icon.svg` y `sw.js` en la raíz.
3. Haz clic en **Commit changes** y espera a que GitHub Pages publique los cambios.
4. En Android, abre `https://juanpa-hero.github.io/Gouki-y-D-D/` en Chrome, toca el menú **⋮** y elige **Instalar aplicación** o **Añadir a pantalla de inicio**.
5. Si no aparece inmediatamente, actualiza la página y espera un poco; la disponibilidad de instalación depende del navegador.

Las marcas y cartas personalizadas siguen guardándose localmente en cada navegador. Exporta un respaldo antes de cambiar de navegador o dispositivo.
