# Gouki & D/D Card Binder

## Publicar en GitHub Pages

1. Entra en https://github.com/new y crea un repositorio nuevo, por ejemplo `gouki-dd-card-binder`.
2. Si usas GitHub Free, selecciona **Public**.
3. Abre el repositorio y pulsa **Add file → Upload files**.
4. Descomprime este ZIP en tu dispositivo y sube `index.html` (debe quedar en la raíz del repositorio, no dentro de otra carpeta).
5. Pulsa **Commit changes**.
6. Ve a **Settings → Pages**.
7. En **Build and deployment**, selecciona **Deploy from a branch**.
8. Elige la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
9. Espera unos minutos y vuelve a **Settings → Pages** para pulsar **Visit site**.

La URL pública suele tener este formato:
`https://TU-USUARIO.github.io/gouki-dd-card-binder/`

Reemplaza `TU-USUARIO` por tu usuario real de GitHub y el nombre del repositorio por el que hayas creado.

## Importante
- Sube el archivo `index.html` extraído; no subas únicamente el ZIP esperando que GitHub Pages lo descomprima.
- GitHub Pages publica el contenido de forma pública.
- Las marcas y cartas personalizadas se guardan en el almacenamiento local del navegador de cada dispositivo. Usa **Exportar respaldo** para guardar una copia y **Importar respaldo** para recuperarla.
